# type.com Skills Library

Agent skills for engineering, sales, marketing, finance, operations, and more. Browse the [public library](https://type.com/library/skills).

This snapshot contains **90 individual skills and 3 skillsets**, exported from the published Type catalog on **October 21, 2026**. All 837 source files are included.

## Use a skill

Clone this repository, then copy the selected skill directory and its required skills into your agent’s skills directory. Keep the complete folder, including scripts, references, assets, and license files.

```sh
git clone https://github.com/type-dot-com/type.com-skills-library.git
cd type.com-skills-library
mkdir -p ~/.agents/skills
cp -R skills/footage-indexer ~/.agents/skills/
```

For Claude Code, use `~/.claude/skills/` instead. For other agents, use their supported Agent Skills installation directory. You can also choose **Use Skill** on a listing’s Type page.

Some skills require connected services, credentials, or local tools. Read each skill’s instructions and its catalog requirements before use.

## Dependencies and skillsets

`catalog.json` records original listing metadata, author credits, requirements, and file hashes. Each listing’s `installSkills` array gives the complete, deduplicated set of directories to copy from `skills/`, including transitive dependencies.

Skillsets group existing skills; their guides are not installable skills. Their original `SKILL.md` is preserved byte-for-byte as `skillsets/<slug>/GUIDE.md`. All other source paths and contents are preserved.
