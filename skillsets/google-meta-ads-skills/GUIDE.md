# Google & Meta Ads

This skillset packages ordinary portable skills. It does not create a new runtime, grant ad-account authority, connect sources, or schedule work.

## Start with your definitions

Use Paid Media Operating Definitions to locate or capture the business's accounts, goals, targets, limits, evidence thresholds, and actual permissions. It reuses Marketing Measurement and Revenue Definitions. Keep the approved answers once in scoped business documents; all workflows read the same versions. Missing choices block only dependent calculations or actions.

## Use the collection

1. Install the desired ordinary skills and their required definitions. Type resolves the declared dependencies; on other agent hosts, install/load the prerequisite skills by name as described in each SKILL.md. The public instructions and reference files remain ordinary Markdown.
2. Open the relevant command center for task routing, or invoke a specialist directly. Specialists depend on the shared definitions, not on either command center.
3. Use actual available integrations or approved exports and cite account/period/source/definition versions in results. Label unknowns, lag and sample limits.
4. Request a specific analysis or provide separately authorized cadence and recipients. Prepare proposed mutations for review unless an actual user grant covers the exact change. Verify any authorized write before claiming it succeeded.

Marketing Measurement and Revenue Definitions are shared prerequisites reused from the library, not duplicated members authored by this collection. Existing Ad Account Audit, Budget Pacer, and Client Report Builder remain optional complementary workflows.
