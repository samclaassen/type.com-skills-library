# Ticket to demo script

> Navattic MCP Skill · Demo scripting

Turns an engineering ticket or changelog entry into a first-draft demo script.

## Workflow

1. Pull the ticket or changelog content: what to show, audience, context.
2. Apply the top-performer pattern for structure.
3. Pull brand voice and product facts via get_workspace_knowledge.
4. Draft a step-by-step script for a builder to review and refine.
